## Engineering Principles

<table width="100%">
  <tr>
    <td width="25%" valign="top"><b>Decouple cleanly</b><br/><sub>Clear boundaries between domain logic, state, and transport.</sub></td>
    <td width="25%" valign="top"><b>Stay fast</b><br/><sub>Indexed reads, efficient queries, and async I/O by default.</sub></td>
    <td width="25%" valign="top"><b>Design for failure</b><br/><sub>Retries, graceful fallbacks, and circuit breakers.</sub></td>
    <td width="25%" valign="top"><b>Measure everything</b><br/><sub>If it isn't monitored and traced, it isn't done.</sub></td>
  </tr>
</table>
